# my-first

A starter repository for experiments, small applications, and learning projects.

## Getting started

This repository does not currently contain application source code or a build system.

1. Add your first project files.
2. Document the language, runtime, and dependencies.
3. Add a test command and a short description of expected behavior.
4. Keep generated files, local environment files, and credentials out of Git.
